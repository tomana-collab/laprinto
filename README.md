# Laprinto CRM

CRM פנימי לעסק laprinto.

## פיתוח מקומי

```bash
npm install
cp .env.example .env   # למלא VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY
npm run dev
```

## Stack

React 18 + TypeScript + Vite + Tailwind CSS + react-router-dom + TanStack Query + Supabase + react-hook-form + zod + sonner + lucide-react.

ראו [CLAUDE.md](./CLAUDE.md) לפרטי חיבורים מלאים.
